Pipeline de traitement

— Les 4 étapes de chaque recherche
🧠
Étape 1

Construction du contexte

Vecteur de goût stable (150 j) Vecteur récent (21 j) Vecteur d'évitement (60 j) Plateformes actives Films exclus (déjà vus) Langue préférée Décennie

Mode duo — les deux vecteurs sont fusionnés par moyenne pondérée (poids = nombre d'interactions). Les plateformes sont l'intersection des deux listes.
Mode vocal — pick-chat → extract_search_intent extrait genre, ambiance, époque, acteur, durée, langue.

↓
🗄️
Étape 2

Filtre SQL — requête vectorielle

Requête cosinus 32 dimensions sur movie_embeddings via match_movies_for_recommendation. Filtres optionnels : plateforme, langue, décennie, exclusions.

200
candidats — sans filtre plateforme
300
candidats — filtre plateforme actif ou duo
↓
⚖️
Étape 3

Présélection — tri avant LLM

Similarité cosinus — 70 %
Note TMDB — 20 %
Popularité — 10 %
Top 20 films → LLM (solo) Top 30 films → LLM (duo)
↓
✨
Étape 4

Évaluation LLM — movie-match

Entrées LLM
  • Films candidats (titre, genres, synopsis, année)
  • Vecteur(s) de goût utilisateur
  • Contexte de recherche actif
  • Seuil minMatchScore du profil
→
Sorties LLM
  • Score d'adhésion 0 – 100
  • Texte de recommandation personnalisé (2–4 phrases)
  • Classement suggéré

Filtre post-LLM : seuls les films au-dessus du seuil sont retenus. Si insuffisant → tolérance +10 pts automatique.
En mode duo, le texte mentionne explicitement les goûts des deux personnes.

Fonctionnalité Match

— "Ce film me correspond ?"

L'utilisateur saisit le nom d'un film ou scanne son affiche (caméra ou photo). Pick vérifie l'historique et répond de deux façons selon ce qu'il trouve.

🔎

Saisie texte

L'utilisateur tape le nom du film. Résolution via l'API TMDB Search → TMDB ID.

TMDB Search API
📷

Scan d'affiche

Photo ou caméra. Claude Vision extrait le titre + l'année → résolution TMDB. Fallback : champ texte pré-rempli à confirmer.

Claude Vision
Film déjà connu
💬

Fiche interaction

  • ·Badge interaction (like / love / watchlist / dislike…)
  • ·Date de l'interaction
  • ·Plateformes actuelles (rechargées en live)
  • ·Action : modifier l'interaction
ou
Film jamais vu
✨
Résultat

Évaluation LLM

  • ·1 film envoyé à movie-match (pas de batch)
  • ·Score d'adhésion 0 – 100
  • ·Texte personnalisé "pourquoi ce film te correspond"
  • ·Plateformes disponibles
  • ·Actions : like / watchlist / dislike / affiner

Le film n'a pas besoin d'être dans movie_embeddings — l'évaluation utilise les métadonnées TMDB brutes + le profil.
